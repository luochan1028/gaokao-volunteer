# 高考志愿填报系统 - 部署指南

> 本文档供 AI Agent 或运维人员参考，用于将高考志愿填报系统部署到任意 Linux 服务器。

## 项目概述

- **技术栈**：Spring Boot 3.2 (Java 17) + Vue 3 + Vite 5 + Element Plus + H2 Database
- **项目结构**：
  - `backend/` - Spring Boot 后端，端口 8080
  - `frontend/` - Vue 3 前端，构建后为静态文件
- **功能特性**：
  - 4种主题皮肤切换（暗色科技/亮色简约/青色海洋/紫色梦幻）
  - 短信验证码注册（Demo模式直接返回验证码）
  - 院校/专业查询、智能推荐、志愿编排、风险评估
  - 所有数值保留2位小数
  - 响应式布局，玻璃拟态卡片风格

## 方案一：本地构建 + SCP 上传（推荐，最快）

**适用场景**：开发机有完整构建环境，服务器只需运行

### 前置条件

**开发机（构建用）**：
- JDK 17+
- Maven 3.9+
- Node.js 18+
- npm / pnpm
- SSH / SCP 工具

**目标服务器（运行用）**：
- Linux (Ubuntu 20.04+ / CentOS 7+ 均可)
- JDK 17+ (只需 JRE 也可以)
- Nginx
- 至少 1GB 内存，1GB 磁盘空间

### 部署步骤

#### 步骤 1：本地构建后端

```bash
cd gaokao-volunteer/backend
mvn clean package -DskipTests -q
```

构建产物：`backend/target/gaokao-volunteer-1.0.0.jar`（约 70MB）

#### 步骤 2：本地构建前端

```bash
cd gaokao-volunteer/frontend
npm install
npm run build
```

构建产物：`frontend/dist/` 目录

#### 步骤 3：上传文件到服务器

```bash
# 打包前端
cd frontend && zip -r ../frontend-dist.zip dist && cd ..

# 上传到服务器（替换 user@server 为实际地址）
scp backend/target/gaokao-volunteer-1.0.0.jar user@server:/tmp/
scp frontend-dist.zip user@server:/tmp/
```

#### 步骤 4：服务器上部署

SSH 登录服务器后执行：

```bash
# 创建部署目录
APP_DIR="/opt/gaokao-volunteer"
mkdir -p "$APP_DIR/backend" "$APP_DIR/frontend"

# 解压文件
mv /tmp/gaokao-volunteer-1.0.0.jar "$APP_DIR/backend/"
unzip -o -q /tmp/frontend-dist.zip -d "$APP_DIR/frontend/"
rm -f /tmp/frontend-dist.zip
```

#### 步骤 5：配置 Nginx

创建 `/etc/nginx/sites-available/gaokao`：

```nginx
server {
    listen 80;
    server_name _;
    root /opt/gaokao-volunteer/frontend/dist;
    index index.html;

    # SPA 路由回退
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理到后端
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 30s;
        proxy_read_timeout 30s;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

启用配置：

```bash
ln -sf /etc/nginx/sites-available/gaokao /etc/nginx/sites-enabled/gaokao
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

#### 步骤 6：创建后端 systemd 服务

创建 `/etc/systemd/system/gaokao-backend.service`：

```ini
[Unit]
Description=Gaokao Volunteer Backend Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/gaokao-volunteer/backend
ExecStart=/usr/bin/java -jar -Xms256m -Xmx512m gaokao-volunteer-1.0.0.jar
Restart=always
RestartSec=10
StandardOutput=append:/opt/gaokao-volunteer/backend.log
StandardError=append:/opt/gaokao-volunteer/backend.log

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
systemctl daemon-reload
systemctl enable gaokao-backend
systemctl start gaokao-backend
```

#### 步骤 7：验证

```bash
# 验证后端
curl http://localhost:8080/api/public/colleges?page=0

# 验证前端
curl http://localhost/

# 验证 Nginx 代理 API
curl http://localhost/api/public/colleges?page=0
```

全部返回 HTTP 200 即部署成功。

### 常用运维命令

```bash
# 重启后端
systemctl restart gaokao-backend

# 查看后端日志
tail -f /opt/gaokao-volunteer/backend.log

# 重启 Nginx
systemctl reload nginx

# 更新前端（重新上传 dist 后）
unzip -o -q frontend-dist.zip -d /opt/gaokao-volunteer/frontend/

# 更新后端（重新上传 jar 后）
systemctl restart gaokao-backend
```

## 方案二：Docker 镜像部署（最快，适合多服务器）

**适用场景**：需要在多台服务器快速部署，或服务器上不想装 JDK/Node 环境

### 前置条件

- 服务器已安装 Docker 和 Docker Compose
- 能访问镜像仓库（GitHub Container Registry 或 Docker Hub）

### 部署步骤

#### 一键部署

```bash
# 下载 docker-compose.yml
curl -O https://raw.githubusercontent.com/luochan1028/gaokao-volunteer/main/docker-compose.yml

# 启动服务
docker-compose up -d
```

访问 `http://服务器IP/` 即可使用。

#### 手动部署

```bash
# 拉取镜像
docker pull ghcr.io/luochan1028/gaokao-backend:latest
docker pull ghcr.io/luochan1028/gaokao-frontend:latest

# 启动后端容器
docker run -d \
  --name gaokao-backend \
  --restart unless-stopped \
  -p 8080:8080 \
  -e JAVA_OPTS="-Xms256m -Xmx512m" \
  ghcr.io/luochan1028/gaokao-backend:latest

# 启动前端容器（需配置反代后端地址）
docker run -d \
  --name gaokao-frontend \
  --restart unless-stopped \
  -p 80:80 \
  --link gaokao-backend:backend \
  ghcr.io/luochan1028/gaokao-frontend:latest
```

### 更新版本

```bash
docker-compose pull
docker-compose up -d
```

## 方案三：服务器上源码构建（不推荐，慢）

**适用场景**：服务器网络好，内存足够（至少 2GB）

### 前置条件

- JDK 17+
- Maven 3.9+
- Node.js 18+
- Nginx
- Git

### 部署步骤

```bash
# 1. 安装依赖（Ubuntu）
apt-get update
apt-get install -y openjdk-17-jdk maven nodejs nginx git

# 2. 克隆代码
git clone https://github.com/luochan1028/gaokao-volunteer.git /opt/gaokao-volunteer
cd /opt/gaokao-volunteer

# 3. 构建后端（慢，需下载 Maven 依赖）
cd backend
mvn clean package -DskipTests -q

# 4. 构建前端（慢，需下载 npm 依赖）
cd ../frontend
npm install
npm run build

# 5. 配置 Nginx 和 systemd 服务（同方案一的步骤 5-6）
```

## 常见问题排查

### 1. 前端页面空白

检查 Nginx 的 root 路径是否正确，静态资源文件是否存在：

```bash
ls /opt/gaokao-volunteer/frontend/dist/
curl http://localhost/assets/index-*.js
```

**注意**：`root` 指令必须放在 `server` 块级别，不能只放在 `location /` 里，否则正则匹配的静态资源 location 会找不到文件。

### 2. API 返回 404

检查后端是否启动，以及 Nginx 代理配置：

```bash
# 检查后端进程
ps aux | grep gaokao

# 直接访问后端
curl http://localhost:8080/api/public/colleges?page=0

# 通过 Nginx 访问
curl http://localhost/api/public/colleges?page=0
```

### 3. 后端启动失败

查看日志：

```bash
tail -100 /opt/gaokao-volunteer/backend.log
```

常见原因：
- 端口 8080 被占用 → `fuser -k 8080/tcp` 杀掉占用进程
- 内存不足 → 调小 JVM 参数 `-Xmx256m`
- Java 版本不兼容 → 确认是 Java 17+

### 4. 主题切换不生效

检查浏览器控制台是否有 CSS 加载错误。确保 `tech-theme.css` 中的 4 个主题选择器都正确定义：

- `[data-theme="dark"]` - 暗色科技
- `[data-theme="light"]` - 亮色简约
- `[data-theme="ocean"]` - 青色海洋
- `[data-theme="purple"]` - 紫色梦幻

### 5. 注册验证码收不到

本项目为 Demo 模式，验证码不会真的发短信，而是：
- 点击"获取验证码"后，后端生成 6 位随机码
- 接口直接返回验证码明文
- 前端弹窗显示验证码
- 注册时校验验证码是否匹配

如果点击"获取验证码"没反应，检查浏览器控制台网络请求，确认 `/api/auth/send-code` 接口是否正常返回。

## 更新部署

### 更新代码

```bash
# 1. 本地重新构建
cd gaokao-volunteer
cd backend && mvn clean package -DskipTests -q && cd ..
cd frontend && npm run build && cd ..

# 2. 上传
scp backend/target/gaokao-volunteer-1.0.0.jar user@server:/tmp/
cd frontend && zip -r ../frontend-dist.zip dist && cd ..
scp frontend-dist.zip user@server:/tmp/

# 3. 服务器上更新
ssh user@server
mv /tmp/gaokao-volunteer-1.0.0.jar /opt/gaokao-volunteer/backend/
unzip -o -q /tmp/frontend-dist.zip -d /opt/gaokao-volunteer/frontend/
systemctl restart gaokao-backend
```
